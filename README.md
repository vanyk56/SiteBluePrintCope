# site-blueprint

**Ссылка на сайт → `SITE_CLONE_BLUEPRINT.md` + стартовый проект Next.js + Tailwind**, по которому ИИ-кодер (Cursor, Claude Code, Codex, Windsurf) собирает копию сайта 1:1.

```
URL ─► Playwright-краулер ─► анализатор дизайн-системы ─► LLM (GLM-5.3-Flash / Gemini / DeepSeek / …) ─► SITE_CLONE_BLUEPRINT.md
        все страницы до глубины N    токены, компоненты,         визуальный разбор скриншотов,           + project/ (Next.js + Tailwind v4)
        скриншоты, CSS, SVG, тексты  Tailwind-классы, адаптив    примитивы, риски, порядок сборки
```

## Что делает

1. **Краулер (Playwright, Chromium)** обходит сайт по внутренним ссылкам и sitemap до глубины `--depth`, соблюдает `robots.txt`, закрывает cookie-баннеры, прокручивает страницу (lazy-load), ждёт шрифты и картинки. Страницы одного шаблона (`/blog/*`) берёт выборочно (`--per-template`).
2. **На каждой странице (десктоп 1440px + мобильный 390px):**
   - полноразмерные скриншоты + кадры каждой секции, скриншоты выпадающих меню и мобильного меню;
   - **computed CSS** каждого элемента: HEX-цвета, шрифты, размеры, отступы, скругления, тени, градиенты, transitions, анимации; авторские media queries (брейкпоинты элементов);
   - все **SVG** (очищенные, `currentColor`, `<use>` развёрнуты), картинки, фоновые картинки, видео, шрифты (`@font-face`) — скачиваются в `project/public/`;
   - все **тексты**, включая скрытые: ответы аккордеонов, панели табов, пункты dropdown/бургер-меню, hover-состояния (реально наводит мышь и замеряет);
   - **чистый DOM** без `<script>`, трекеров и обработчиков (`dom/*.html`).
3. **Анализатор** находит секции (Navbar/Header, Hero, логотипы, Features/карточки, Stats, Pricing, Testimonials, Tabs, FAQ, формы, CTA, блог, команда, Footer…), общие блоки между страницами, повторяющиеся элементы, собирает дизайн-токены (палитра с ролями `primary / foreground / muted / border…`, типографическая шкала, отступы, контейнеры, радиусы, тени) и переводит всё в **Tailwind v4** (`@theme` + классы с адаптивными префиксами `md:` / `lg:`).
4. **LLM** (по умолчанию **DeepSeek V4.1 Flash** через River AI; любая модель с OpenAI-совместимым API) смотрит на скриншоты и данные и дописывает: дизайн-язык, визуальные правки к каждому компоненту, UI-примитивы, порядок сборки, риски, дополнения к мастер-промпту. Без ключа инструмент тоже работает — блюпринт получается детерминированным, просто без нейро-разбора.
5. **Результат** — `SITE_CLONE_BLUEPRINT.md`:
   - **§0 мастер-промпт** «Ты Senior Frontend инженер. Используя спецификацию ниже, собери проект на Next.js + Tailwind CSS…»
   - §1 обзор страниц · **§2 дизайн-токены** (таблицы + готовый `app/globals.css` для Tailwind v4)
   - **§3 ассеты**: все SVG-иконки и логотипы как чистый TSX-код (`components/icons.tsx`), картинки, шрифты, favicon/OG
   - **§4 контент 1:1** по страницам и компонентам
   - **§5 архитектура**: `Header.tsx`, `HeroSection.tsx`, `FeaturesSection.tsx`, `PricingSection.tsx`, `Footer.tsx`…
   - **§6 компоненты**: факты DOM/CSS, скриншот, разбор LLM и готовый TSX-код каждого компонента
   - §7 скрытый контент и интерактив · §8 адаптив и анимации · §9 QA-чеклист

## Установка

Нужен **Node.js 20.12+**.

```bash
npm install
npx playwright install chromium      # или: npm run setup
cp .env.example .env                  # и впиши LLM_API_KEY
```

Ключ Z.ai: зарегистрируйся на z.ai → API Keys. Если у тебя GLM Coding Plan, поставь `LLM_PROVIDER=zai-coding`.

## Запуск

```bash
node bin/site-blueprint.mjs https://example.com --depth 2
npm start                              # спросит ссылку
node bin/site-blueprint.mjs example.com -d 1 -p 5 --no-llm
```

Результат: `output/<домен>-<дата-время>/`.

| Путь | Что внутри |
| --- | --- |
| `SITE_CLONE_BLUEPRINT.md` | главный документ для ИИ-кодера |
| `project/` | стартовый Next.js 16 + Tailwind v4 проект: layout, страницы, секции, иконки, токены, картинки и шрифты в `public/` |
| `screenshots/` | `desktop/`, `mobile/`, `sections/`, `interactions/` (dropdown, бургер), `llm/` (кадры, отправленные в модель) |
| `content/*.md` | тексты каждой страницы в Markdown |
| `pages/*.md` | подробности по каждой странице (если блюпринт большой, код уходит сюда) |
| `dom/*.html` | чистый DOM без скриптов |
| `data/` | `crawl.json` (страницы, пропуски, ассеты), `design-tokens.json`, сырые данные страниц, CSS, ответы LLM (`llm/`, кэш) |

**Как использовать:** открой папку результата в Cursor / Claude Code / Codex, скопируй мастер-промпт из §0 и дай ссылку на `SITE_CLONE_BLUEPRINT.md`. Агент начинает с `project/` (`npm install && npm run dev`) и доводит секции до совпадения со скриншотами.

**Пересборка без обхода** (например, сменил модель или ключ):

```bash
node bin/site-blueprint.mjs --from output/example.com-20250101-1200 --provider gemini --model gemini-2.5-flash
```

Ответы LLM кэшируются в `data/llm/` — повторный запуск с теми же данными и моделью не тратит токены.

| Флаг | По умолчанию | Описание |
| --- | --- | --- |

| `-p, --max-pages <n>` | 15 | максимум страниц |
| `--per-template <n>` | 2 | сколько страниц одного шаблона брать (`/blog/*`) |
| `--concurrency <n>` | 2 | параллельных страниц |
| `--viewport`, `--mobile-viewport` | 1440x900, 390x844 | размеры окна |
| `--no-mobile` | | без мобильного прохода |
| `--no-hover`, `--no-interactions` | | без замеров hover / табов / аккордеонов |
| `--no-assets` | | не скачивать картинки и шрифты |
| `--ignore-robots` | | игнорировать robots.txt (только для своих сайтов) |
| `--subdomains` | | разрешить поддомены |
| `--locale ru-RU` | | язык браузера |
| `--headful` | | показать окно браузера |
| `--delay <ms>`, `--timeout <ms>` | 300, 45000 | пауза между страницами, таймаут загрузки |
| `--max-nodes <n>` | 4000 | лимит DOM-узлов на страницу |
| `--max-assets <n>`, `--max-asset-mb <n>` | 400, 15 | лимиты на скачивание ассетов |
| `--no-sitemap`, `--no-cookies`, `--no-html` | | без sitemap.xml / без закрытия cookie-баннеров / без `dom/*.html` |
| `--provider <id>` | zai | `zai`, `zai-coding`, `zhipu`, `gemini`, `deepseek`, `openrouter`, `openai`, `ollama`, `custom` |

| `--max-images <n>` | 6 | скриншотов на страницу |
| `--no-llm` | | без нейросети |
| `-o, --out <dir>` | output | папка результатов |
| `--lang ru/en` | ru | язык ответов LLM |
| `--from <dir>` | | пересобрать из прошлого запуска |
| `-v, --verbose` | | подробный лог |

## LLM-провайдеры

Все подключаются через OpenAI-совместимый `/chat/completions` — настройки в `.env` (см. `.env.example`).

| Провайдер | `LLM_PROVIDER` | Скриншоты | Примечание |
| --- | --- | --- | --- |
| River AI (DeepSeek V4.1 Flash) | `river` (по умолчанию) | да | endpoint `https://api.river.ai/v1` |
| Z.ai GLM-5.3-Flash | `zai` | да | temperature 1.0, top_p 0.95 |
| Z.ai Coding Plan | `zai-coding` | да | endpoint `/api/coding/paas/v4` |
| Google Gemini | `gemini` | да | OpenAI-совместимый endpoint Gemini API |
| DeepSeek | `deepseek` | нет | только текст и данные |
| OpenRouter | `openrouter` | зависит от модели | |
| OpenAI | `openai` | да | |
| Ollama | `ollama` | зависит от модели | локально, без ключа |
| Любой другой | `custom` + `LLM_BASE_URL` | настраивается | vLLM, LM Studio, прокси |

Если модель не принимает картинки, инструмент сам переключится на текстовый режим. Ошибки 429/5xx повторяются с паузой; при неверном ключе (401/403) LLM-шаг пропускается, а блюпринт всё равно собирается.

## Ограничения

- Canvas/WebGL, сложные JS-анимации и видео-фоны переносятся по скриншотам и ассетам, а не кодом.
- Сайты с жёсткой анти-бот защитой, капчей или страницами за логином могут не обойтись.
- Каркас в `project/` — сильная стартовая точка, а не пиксель-перфект: финальную подгонку делает ИИ-кодер по скриншотам и блюпринту.
- Очень большие страницы усекаются (`--max-nodes`, по умолчанию 4000 узлов); блюпринт автоматически сокращается, если превышает ~450 тыс. символов (код уходит в `pages/*.md`).

## Законность и этика

Используй инструмент для **своих сайтов** или сайтов, на копирование которых у тебя **есть права** (редизайн, миграция, аудит дизайн-системы, конкурентный анализ без публикации копии). Тексты, изображения, логотипы и шрифты защищены авторским правом и товарными знаками — не публикуй чужой контент и бренд. По умолчанию соблюдается `robots.txt`, есть пауза между запросами и учёт `crawl-delay`; трекеры и аналитика блокируются при обходе, а в `dom/*.html` и `project/` нет скриптов исходного сайта.
