    Настройки

    Без доступа к сайту захват идёт через activeTab: только эта вкладка и только по клику. API без перезагрузки: ответы, пойманные во время захвата, и повтор GET-запросов из Resource Timing.

    Клонируй только свои сайты или с разрешения владельца. Токены, cookies, e-mail и телефоны вырезаются из захвата. Защиты от ботов не обходятся.
