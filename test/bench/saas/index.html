Developers

Three calls to production

Create a collection, upsert your documents and query. Vectorly handles chunking, embeddings and caching.

  • Automatic chunking for PDF, HTML and Markdown
  • Bring your own embedding model or use ours
  • Streaming results with relevance scores
// npm i @vectorly/sdk
import { Vectorly } from '@vectorly/sdk';

const vx = new Vectorly({ key: process.env.VX_KEY });
const docs = vx.collection('support-articles');

await docs.upsert(articles);
const hits = await docs.query({
  text: 'how do I rotate my API key?',
  topK: 5, hybrid: true,
});
